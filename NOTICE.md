# Notice

This is a personal tool. It was built October–November 2025 for the author's own use in
tracking NNS neurons, set aside, and picked back up in August 2026 for correctness and
release work.

**On the data.** Neuron IDs, principals, stake and balance figures in the documentation and
test fixtures are synthetic — obviously-shaped placeholders chosen to keep the file formats
accurate.

This repository is shared because some of what it works out — the reward-window handling, the
NNS bonus-curve correction, the provenance marker — seemed useful to anyone tracking neurons.
It is not a product launch, and nothing here is offered as a service or supported.
