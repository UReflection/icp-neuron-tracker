## What is not here, and why

**`docs/features/`** — removed. Six specifications, 8,535 lines, all either describing work
that had already shipped or a CSV format that never existed.

**`docs/strategy/`** — removed; not product documentation.

**`docs/api/`, `docs/concepts/`, most of `docs/guides/`** — never existed. The previous
index listed roughly twenty-five such files as though they did.

---

## Where documentation and code disagree

**Code wins.** The docs led the code in several places and some of that remains
uncorrected. Known conflicts are listed under "Known doc/code conflicts" in
[CLAUDE.md](../CLAUDE.md); the significant one remaining is ADR-003, which is marked Accepted
against a single-crate tree.

If you find a disagreement not listed there, trust the code and the `--help` output, and
record it rather than silently resolving it.

---

## Adding to this index

One rule: **do not list a document before it exists.** That single habit is what turned the
previous index into forty broken links out of sixty-two.

Use the [ADR template](decisions/template.md) for decisions. Number sequentially. Superseded
decisions stay in place with a header saying what replaced them — the reasoning trail is the
point.
